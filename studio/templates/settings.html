Claude Desktop chat

Needs Node.js. In Claude Desktop: Settings → Developer → Edit Config, add this (merge it into an existing mcpServers if there is one), then quit and reopen Claude. Start with: "Start a CGW Studio session: call get_guidelines, then work through the queue."

{
  "mcpServers": {
    "cgw-studio": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ addr }}/mcp", "--allow-http",
               "--header", "Authorization:${AUTH_HEADER}"],
      "env": { "AUTH_HEADER": "Bearer {{ new_token }}" }
    }
  }
}
